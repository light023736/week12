# 12주차 실습 결과 보고

## 데이터 출처

- 원본 파일: `scores_2026.csv`
- 작은 테스트 파일: `mini.csv`
- 모든 열: 학번, 이름, 반, 과목, 점수

## 행 수

- 원본 행 수: 114행
- 점수가 비어 있는 행 제거 후
- 완전히 동일한 중복 행 제거 후
- 반과 과목의 앞뒤 공백 제거 후
- 점수가 0~100 범위 밖인 행 제거 후
- 최종 정제 행 수: 100행

## 열 설명

- `학번`: 학생 학번
- `이름`: 학생 이름
- `반`: 학생 반 이름
- `과목`: 시험 과목
- `점수`: 정수인 시험 점수

## 반과 과목 전처리 결과

- 점수가 비어 있는 행을 삭제했다.
- 모든 열이 완전히 같은 중복 행을 하나만 남겼다.
- `반`과 `과목`의 앞뒤 공백을 제거했다.
- 점수가 0 이상 100 이하인 행만 남겼다.
- 최종 정제 후에는 `1반`과 `2반`만 남는다.
